# 🏥 Decision Tree for COVID-19 Analysis
##  Overview
This repository contains a Jupyter Notebook that implements a Decision Tree model for analyzing and predicting COVID-19 cases based on available data, both with and without using the `sklearn` library.
The notebook demonstrates data preprocessing, model training, F1 score calculation, and visualization of the results.

## Features
Data Preprocessing: Handles missing values, feature selection, and data encoding.
Model Training: Implements a Decision Tree Classifier using scikit-learn.
Evaluation Metrics: Includes accuracy, confusion matrix, and classification report.
Visualization: Displays decision tree structure and feature importance.

## Requirements
#### Before running the notebook, install the required dependencies using:
`pip install numpy pandas scikit-learn matplotlib seaborn`

## ▶️ How to Run
#### Clone the repository:
`git clone https://github.com//decision-tree-covid.git`
`cd decision-tree-covid`

#### Launch Jupyter Notebook:
`jupyter notebook`

#### Open `DicisionTree_Covid.ipynb` and execute the cells.

## 📊 Results
The notebook provides insights into COVID-19 case classification using a decision tree model. It includes performance metrics and visualizations to interpret the model’s predictions.
